# TaxiDrive.kz — release verificada 27/09/2026

## Estado
Esta versión fue probada manualmente en un APK funcional antes de actualizar el repositorio.

Flujos comprobados:
- registro y revisión/aprobación de conductores
- datos del vehículo (incluyendo marca, modelo, color, año, matrícula y licencia)
- período gratuito de 1 mes
- activación de 24 horas
- solicitudes de pasajeros
- coincidencia de rutas
- notificaciones de nuevas solicitudes/ofertas
- ofertas del conductor
- aceptación de oferta
- chat asociado a la oferta
- perfiles de conductor
- panel administrativo y usuarios
- idiomas Kazajo, Ruso, Español e Inglés

## Nota de sincronización
El ZIP de lanzamiento aportado para esta revisión corresponde a un paquete de fuente fechado el 02/09/2026 y todavía contiene referencias comerciales a 200 ₸. El APK probado actualmente muestra 500 ₸/24 h.

Por seguridad, no se reemplazó ciegamente el árbol principal de código por ese ZIP, porque eso dejaría GitHub en una versión distinta del APK que acaba de ser probada.

La localización de nombres de ciudades/rutas se deja deliberadamente sin cambios por ahora, tal como se decidió durante las pruebas.

## Siguiente sincronización de código
Cuando tengamos el paquete fuente que corresponda exactamente al APK probado (incluido 500 ₸), se podrá sustituir el árbol de TaxiDrive_v2_beta sin mezclar versiones.
